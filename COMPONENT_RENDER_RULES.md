COMPONENT_RENDER_RULES.md

Versão: 1.0

Objetivo:

Definir como cada componente deve ser representado visualmente no preview 3D.

Este documento não trata de preço.

Este documento não trata de banco de dados.

Este documento não trata de regras comerciais.

Ele trata apenas da representação visual dos componentes.

⸻

COMPONENT_001

Tampo Reto 20 mm

Renderização:

* espessura visual de 20 mm
* textura aplicada em todas as faces
* cantos retos
* sem recortes
* sem área molhada

REGRA GERAL

O preview 3D não inventa geometrias.

O preview 3D apenas renderiza os componentes definidos no catálogo oficial.

Todo novo componente deve possuir uma regra de renderização cadastrada neste documento antes da implementação.
