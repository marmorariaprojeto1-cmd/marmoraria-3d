# Catálogo Mestre de Produtos

Este documento define o catálogo mestre inicial de produtos e opções da plataforma Marmoraria 3D.

O catálogo deve servir como base comum para o SaaS multiempresa. No futuro, cada marmoraria poderá ativar, ocultar, precificar ou personalizar os itens conforme seu próprio catálogo comercial.
