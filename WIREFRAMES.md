# Wireframes Conceituais

Este documento descreve as telas e elementos esperados da plataforma Marmoraria 3D em nível conceitual.

Não representa implementação de frontend, layout final, código ou design visual definitivo.

## 1. Página Inicial

Elementos:

- Header com logo
- Menu simples
- Botão "Montar meu projeto"
- Banner principal
- Texto explicando o simulador
- Cards de tipos de peça
- Pedras em destaque
- Chamada para WhatsApp

## 2. Simulador - Escolha do Ambiente

Elementos:

- Título da etapa
- Cards: Cozinha, Banheiro, Área Gourmet, Escada, Soleira, Peitoril, Comercial
- Botão voltar
- Indicador de progresso

## 3. Simulador - Escolha do Produto

Elementos:

- Produtos filtrados pelo ambiente
- Cards com imagem/ícone
- Nome do produto
- Breve descrição
- Indicador de progresso

## 4. Simulador - Escolha da Pedra

Elementos:

- Lista/grid de pedras
- Foto/textura
- Nome da pedra
- Categoria
- Indicação visual de seleção
- Filtro por categoria

## 5. Simulador - Configuração de Medidas

Elementos:

- Campo largura
- Campo profundidade
- Campo espessura
- Controles de aumentar/diminuir
- Preview visual
- Orçamento parcial em tempo real

## 6. Simulador - Cubas e Recortes

Elementos:

- Escolha de cuba
- Tipo de instalação da cuba
- Posição da cuba
- Recorte para cooktop
- Furações
- Preview atualizado

## 7. Simulador - Acabamentos

Elementos:

- Lista de acabamentos
- Rodabanca
- Saia
- Borda
- Preview atualizado
- Orçamento parcial

## 8. Simulador - Visualização

Elementos:

- Área principal de visualização 2D/3D
- Rotação
- Zoom
- Troca rápida de pedra
- Resumo lateral do orçamento

## 9. Resumo do Orçamento

Elementos:

- Produto escolhido
- Pedra escolhida
- Medidas
- Cuba
- Acabamentos
- Recortes
- Valor estimado
- Botão "Enviar pelo WhatsApp"
- Botão "Solicitar atendimento"

## 10. Formulário do Cliente

Elementos:

- Nome
- Telefone
- Cidade
- E-mail opcional
- Observações
- Botão enviar

## 11. Painel Administrativo

Elementos:

- Login
- Dashboard
- Pedidos recebidos
- Cadastro de pedras
- Cadastro de cubas
- Cadastro de acabamentos
- Configuração de preços
- Configuração do WhatsApp

## 12. Dashboard da Marmoraria

Elementos:

- Total de pedidos
- Pedidos novos
- Orçamentos em negociação
- Orçamentos fechados
- Valor estimado em oportunidades

## 13. Tela de Pedidos

Elementos:

- Lista de pedidos
- Status
- Cliente
- Valor estimado
- Data
- Botão ver detalhes

## 14. Detalhe do Pedido

Elementos:

- Dados do cliente
- Configuração escolhida
- Medidas
- Valores
- Histórico
- Alterar status
- Enviar mensagem

## Diretrizes Visuais

- Interface simples
- Visual moderno
- Poucas etapas por tela
- Foco em mobile
- Botões grandes
- Linguagem clara
