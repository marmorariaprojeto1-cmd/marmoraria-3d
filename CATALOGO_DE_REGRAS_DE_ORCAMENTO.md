# Catálogo de Regras de Orçamento

Este documento define as regras iniciais para composição de orçamento na plataforma Marmoraria 3D.

As regras devem nascer preparadas para SaaS multiempresa. Cada marmoraria poderá configurar seus próprios preços, multiplicadores, margens e critérios comerciais.

## Conceito Geral

Todo orçamento será composto por:

Preço da Pedra
+
Acabamentos
+
Cubas
+
Recortes
+
Furações
+
Rodabancas
+
Saias
+
Instalação
+
Frete
+
Margem da Marmoraria

## Cálculo da Área

Definir padrão:

Área = largura x profundidade

Resultado em m².

## Espessuras

Permitir configuração por empresa:

- 2 cm
- 3 cm
- 4 cm

Cada espessura poderá possuir multiplicador próprio.

Exemplo:

2 cm = 1,00
3 cm = 1,15
4 cm = 1,30

## Pedras

Cada pedra deverá possuir:

- Nome
- Categoria
- Preço por m²
- Disponível para orçamento
- Multiplicador opcional

Categorias iniciais:

- Granito
- Mármore
- Quartzo
- Quartzo industrializado
- Porcelanato
- Dekton
- Nanoglass

## Cubas

Cada cuba deverá possuir:

- Nome
- Categoria
- Preço fixo
- Ativa/Inativa

## Acabamentos

Cada acabamento deverá possuir:

- Nome
- Tipo de cobrança

Tipos:

- Valor fixo
- Valor por metro linear
- Percentual

## Rodabancas

Configurar:

- Altura
- Comprimento
- Valor por metro linear

## Saia

Configurar:

- Altura
- Comprimento
- Valor por metro linear

## Recortes

Permitir:

- Cooktop
- Cuba
- Tomadas
- Personalizados

Cada um com preço próprio.

## Furações

Permitir:

- Torneira
- Dosador
- Misturador
- Personalizada

Cada uma com preço próprio.

## Instalação

Permitir:

- Valor fixo
- Valor por faixa de metragem
- Valor por cidade

## Frete

Permitir:

- Valor fixo
- Faixa por distância

## Margem

Cada empresa poderá definir:

- Margem percentual padrão
- Margem por categoria de pedra

## Fórmula Final

Valor Final =
Pedra
+ Cubas
+ Acabamentos
+ Rodabancas
+ Saias
+ Recortes
+ Furações
+ Instalação
+ Frete
+ Margem
